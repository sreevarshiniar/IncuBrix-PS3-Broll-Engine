# Test pack and evidence index

This folder must contain the actual outputs and logs from tests run against the submitted version. Do not add fabricated results.

## Existing test inputs

- `../test_inputs.jsonl` — seed JSONL cases included in the repository. Review them and add varied cases for tutorials, product explainers, narrative/story, abstract statements, statistics, ambiguous words, sensitive topics, invalid input, silent audio, and provider failure.
- `pytest-output.txt` — save the real output from `python -m pytest -q` here.
- `batch-results.json` — generated by the batch runner; preserve both successful and failed cases.
- `relevance-ratings.csv` — create a row for every scene in ten varied videos and manually score relevance 1–5 with a short reason. Automated similarity scores are not human ratings.
- `ffprobe-results.txt` — record actual codec, dimensions, frame rate, duration and audio stream checks for each final video.

## Run tests

```powershell
python -m pytest -q 2>&1 | Tee-Object -FilePath test-pack/pytest-output.txt
python scripts/batch_runner.py test_inputs.jsonl --base-url http://localhost:8000 --out test-pack/batch-results.json
```

Run the API before the batch command. Inspect the returned job status and outputs; a 202 response only means that a job was accepted, not that rendering succeeded.
